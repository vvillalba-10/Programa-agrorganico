# AgrOrgánico - Plataforma de Gestión para Agricultura Orgánica 

AgrOrgánico es una plataforma digital Full-Stack diseñada como una solución social para agricultores y productores. El sistema permite optimizar la gestión de cultivos, realizar el seguimiento detallado de análisis de suelos y administrar datos estructurados de fertilizantes orgánicos, promoviendo prácticas agrícolas sostenibles y eficientes.

##  Características Principales

- **Gestión de Cultivos:** Módulo completo para el registro, seguimiento y control cronológico de diferentes tipos de siembras.
- **Análisis de Suelos:** Almacenamiento y consulta de parámetros críticos del terreno para la toma de decisiones agrícolas.
- **Control de Fertilizantes:** Base de datos integrada para la dosificación y gestión de componentes orgánicos.
- **Diseño Adaptativo (Responsive):** Interfaz optimizada para una visualización fluida tanto en computadoras de escritorio como en dispositivos móviles.

## Tecnologías Utilizadas

### Backend y Base de Datos
- **Node.js:** Entorno de ejecución para el servidor.
- **Express.js:** Framework para la construcción de la API y el enrutamiento.
- **MySQL:** Motor de base de datos relacional para el almacenamiento seguro de la información.
- **MySQL Workbench:** Herramientas de modelado EER y diseño de esquemas relacionales.

### Frontend
- **HTML & CSS3:** Estructura y estilos nativos de la aplicación.
- **Bootstrap:** Framework de diseño para garantizar una interfaz moderna, ágil y adaptativa.

## 📐 Arquitectura de Datos

El proyecto cuenta con un modelo de base de datos relacional minuciosamente normalizado, estructurado mediante relaciones lógicas que garantizan la integridad de la información y eliminan la redundancia de datos.
